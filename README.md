# Fit & Denim

Jednostránkový web (čisté HTML/CSS/JS, bez build kroku). Logo je vložené přímo v `index.html`.

## Nasazení na Vercel
1. Nahrajte složku do GitHub repozitáře.
2. Na vercel.com: Add New → Project → vyberte repozitář.
3. Framework Preset: **Other**, Build Command a Output Directory nechte prázdné → Deploy.
